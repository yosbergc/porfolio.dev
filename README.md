# Yosber Guerrero — Portfolio

Personal portfolio for Yosber Guerrero, full stack developer and programming content creator. The site is a bilingual (English/Spanish) editorial portfolio built around a responsive bento grid, real client screenshots and project case studies.

## Stack

- **Astro 5** with static output
- **Tailwind CSS 3** with custom design tokens and dark mode
- **TypeScript** in strict mode
- **Typed data modules** for projects, experience and side projects (no CMS or content collections required)
- **Astro i18n routing** with English at `/` and Spanish at `/es/`
- **@fontsource-variable/onest** for the variable typeface
- **sharp** for Astro image optimization (direct dependency required by Astro’s image service)

## Commands

```sh
pnpm install
pnpm dev        # local development
pnpm build      # astro check + astro build
pnpm preview    # preview the production build
```

There are no separate lint or test scripts in the repository. The `build` script runs `astro check` before generating the site.

## Structure

```text

  assets/                  Portrait and real project screenshots
  components/              Layout sections and UI primitives
  data/
    projects.ts            Six featured projects with localized case-study content
    otherProjects.ts       Existing side projects preserved from the original portfolio
    experience.ts          Work history, localized
    site.ts                Contact links, social profiles and capability groups
  i18n/

    utils.ts               Locale helpers and localized route builders
  layouts/
    Layout.astro           SEO head, theme bootstrapping, header/footer shell
  pages/
    index.astro            English home
    es/index.astro         Spanish home
    work/[slug].astro      English case study
    es/proyectos/[slug].astro
    en/                    Legacy redirects
    sitemap.xml.ts
  styles/
    global.css             Design tokens, bento cards, typography and interaction states
```

## Internationalization

English is the default locale and has no prefix. Spanish uses `/es/`. The interface copy is centralized in `src/i18n/ui.ts`; project, experience and side-project content is stored as `{ en, es }` values in `src/data/`.

The language switcher keeps the equivalent page:

- Home: `/` ↔ `/es/`
- Case studies: `/work/[slug]/` ↔ `/es/proyectos/[slug]/`
- On the home page, the current hash is preserved when switching languages.
- Legacy `/en/...` URLs redirect to the unprefixed English routes.

Each page renders its own `lang`, canonical URL and `hreflang` alternates for English, Spanish and `x-default`. The sitemap also includes the localized alternates.

## Content and research notes

All six featured projects were live at the time of research (October 2026). Screenshots in `src/assets/projects/` are real captures of the public sites, not invented mockups.

Public signals verified during research:

- **FuturaSight Screens** — Astro asset pipeline, Tailwind-style compiled CSS, Cloudflare Insights; public routes `/`, `/login`, `/registro`. Internal dashboard and backend are private.
- **Futura Sight** — Astro asset pipeline, compiled utility CSS, vanilla JavaScript, Vercel Analytics; bilingual `/es/` route.
- **Right At Home Realty Team** — Astro generator metadata, compiled utility CSS, DM Sans Variable, IDX Addons widgets, Vercel Analytics; bilingual `/es` route.
- **Azteca Woodlawn** — Astro v7.0.9 generator metadata, compiled utility CSS, DoorDash ordering, Google Maps Embed API, Vercel Analytics; English route `/en`.
- **Azteca Gastonia** — Astro v7.0.9, compiled utility CSS, Deliverect Direct ordering, VIP rewards link, Google Maps Embed API, Vercel Analytics; bilingual routes.
- **Azteca Smith Corners** — Astro v7.0.9, compiled utility CSS, DoorDash ordering, Google Maps Embed API, Vercel Analytics; Spanish-first content.

The project pages distinguish frameworks, styling, languages, integrations and analytics in the verified-stack list. Internal dashboards, private repositories, CMS configuration, CRM/MLS accounts, form backends and analytics accounts were not inspected; each case study includes a “What I couldn’t verify” section. No traffic, lead, revenue or performance metrics are claimed.

## SEO and accessibility

- Unique titles and descriptions per page and language
- Open Graph and Twitter card metadata
- Canonical links and `hreflang` alternates
- Semantic headings with a single `h1` per page
- Real image dimensions, responsive `srcset`, lazy loading below the fold and eager loading for hero imagery
- Skip link, keyboard-operable navigation and disclosure menu, visible focus styles
- `aria-expanded`, `aria-controls`, `aria-pressed` and accessible labels for controls
- `prefers-reduced-motion` support
- Responsive checks down to 320 px with no horizontal overflow
